    Layout

    One core, three backends

    Nothing under core/ includes a platform header. The device, the SDL simulator and this page compile the same sources, so they cannot drift.

    PathContents
    core/include/wedge/Public headers: canvas, font, spring, scene, message, app.
    core/src/Renderer, text, springs, scene, message cache, ambient bank, state machine.
    core/src/faces/Screens: home, message card, boot, diagnostics. Shared glass and geometry helpers.
    core/src/fonts/Generated glyph atlases. Do not edit; run make fonts.
    platform/sdl/Host simulator, SDL2.
    platform/wasm/Emscripten port. Exports the C API this page drives.
    platform/esp32s3/ESP-IDF project: RM67162, CST816T, Wi-Fi, SNTP, HTTP, NVS.
    server/Next.js backend and sender UI.
    tools/Font baker, headless frame renderer, moon-path test, artifact builder.

    Adding a source file to core/ means adding it to platform/esp32s3/main/CMakeLists.txt. The list is explicit because CMake evaluates a glob once and ESP-IDF rejects CONFIGURE_DEPENDS during its requirement scan, so a globbed build silently fails to link a new file.

    Protocol

    Wire

    Two credentials. The device bearer token authenticates the appliance and can be revoked alone; the sender password never reaches the device. Scheduling is enforced on the device against its NTP clock, so a message is delivered early and held locally.

    MethodPathAuthBody
    GET/api/device/messagesdevice token{messages:[{id,text,type,priority,available_at,expires_at}], server_time}
    POST/api/device/messages/{id}/readdevice tokenIdempotent. {ok:true}.
    GET/api/device/ambientdevice token{lines:[string]}, at most 12.
    GEThttp://192.168.4.1/*setup AP, openCaptive portal. Any path serves the page; any DNS name resolves to it.
    POSThttp://192.168.4.1/savesetup AP, opens=ssid, p=password, form-encoded. Credentials are written only after they connect.
    POST/api/authpasswordSets a 30-day HMAC session cookie.
    GET POST/api/messagessessionList and create. Text capped at 280.
    DELETE/api/messages/{id}session—
    GET PUT/api/ambientsession{lines:[string]}. Replaces the whole bank.

    Storage picks itself from the environment: Upstash Redis if KV_REST_API_* is set, Vercel Blob otherwise, an in-process map when neither is. Blob is public-access with 30-character random pathnames that are never returned to a client; that is unguessable, not access-controlled.

    Constants

    Motion

    Springs, not curves: a curve cannot be re-targeted mid-flight without a jump, and everything here can be grabbed while it moves. Damping ratio and response, integrated with implicit Euler so a long frame cannot destabilise it.

    Unverified

    Known gaps

    Never run on hardware. Everything above compiles, tests and renders. None of it has been seen on the panel.

    Blur cost on device is unmeasured. 1.08 ms per frame on an M-series Mac; on the S3 it is PSRAM-bandwidth bound, not arithmetic bound. config.glass_blur = false disables refraction and blur in one line and the material still reads.

    No thermal work on a sealed shell around an always-on S3.

    OTA is unimplemented. Partitions are laid out for it; there is no update client.

    Fonts are San Francisco and New York, licensed by Apple for interfaces on Apple platforms. Correct for a personal object, wrong for anything distributed. Inter and Newsreader remain in tools/ttf/; the swap is one table in the baker.

    The enclosure is a desk wedge, reclined 54° for a seated eye above a desk. From a pillow it points at the ceiling.
